# GeoResponse web app

React + TypeScript + Vite. No map library, no CDN — a local SVG renderer over the generated data pack.

```bash
npm install
npm run dev       # dev server
npm run build     # tsc + vite build
npm run preview
```

The app reads `public/data/` generated by `py -m georesponse.datapack` from the repository root.
See the root [README](../README.md).
