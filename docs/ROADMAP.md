- [x] Fixed event, fixed tiles, precomputed detections; no live download on stage.

- [x] The time scrub is a rendering of a precomputed sequence, not a live model.
- [x] Stage mode omits the analyst queue; booth mode can show it.
- [x] Provenance panel: imagery source, date, model, real vs simulated.

- [x] Seven of ten viewers can repeat the closing line — scorecard; line is on the reveal and field order.
